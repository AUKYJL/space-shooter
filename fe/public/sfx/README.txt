SPACE SHOOTER — SFX PACK
========================

32 готовых звуковых эффекта в OGG, отобранных из предоставленных архивов.
Все оригинальные OGG скопированы без перекодирования и без изменения громкости.
Музыки в исходных архивах не было: этот ZIP содержит только SFX.

ИСПОЛЬЗОВАНИЕ
- Распакуйте sfx/ в fe/public/sfx/ (если ваш фронтенд раздаёт public/ как корень).
- sound-manifest.json: предлагаемые идентификаторы, URL и начальные значения volume (0–1).
- source-map.csv: для каждого файла — назначение, архив-источник и исходное имя.
- preview.html: открыть в браузере после распаковки для прослушивания каждого эффекта.
- Частые звуки (стрельба, hit, loot) рекомендуется ограничить по параллельному воспроизведению.
- Значения громкости в manifest — предложения для тестирования, а не обработка исходного аудио.
- Для длительного звука extraction-success (~4 с) желательно прекращать воспроизведение при выходе из сцены.
